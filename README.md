# Isi’s Cocktailbar – 40 & Fabulous

## Start
```bash
pip install -r requirements.txt
streamlit run app.py
```

## Online / QR-Code
1. Dieses Verzeichnis in ein **privates GitHub-Repository** hochladen (inkl. `screenshots/`).
2. Auf [share.streamlit.io](https://share.streamlit.io/) mit GitHub anmelden und das Repository deployen (Datei: `app.py`). Beachte: Gratis-Community-Cloud-Apps können öffentlich erreichbar sein; keine privaten persönlichen Daten hochladen.
3. Die dabei **tatsächlich vergebene** `https://...streamlit.app`-Adresse als QR-Code verteilen, z. B. über einen QR-Code-Generator oder Smartphone-Browser.

## Rezeptqualität
Alle 70 originalen Screenshots sind der App zugeordnet und können geöffnet werden. Für 32 gängige Cocktails existieren zusätzlich praxistaugliche, **nicht 1:1 aus den Bildern transkribierte** Textrezepte. Die anderen werden nur als Originalbild dargestellt und sind als solche gekennzeichnet. Die Texte sollten vor der Feier bei den gewünschten Drinks gegen die Bilder gegengeprüft werden.
